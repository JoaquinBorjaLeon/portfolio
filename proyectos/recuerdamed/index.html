Qué haceWhat it does

  • Tres roles con permisos distintos: paciente, cuidador y familiar.Three roles with different permissions: patient, caregiver and family.
  • Pautas diarias, por días de la semana o cada X horas, con un margen para confirmar cada toma.Daily, weekday or every-X-hours schedules, with a time window to confirm each dose.
  • Notificaciones locales de recordatorio, aviso y caducidad, y push a los vinculados.Local reminder, warning and expiry notifications, plus push alerts to linked users.
  • Vinculación con consentimiento mediante invitaciones revocables.Consent-based linking through revocable invitations.
  • Historial de adherencia con tomas confirmadas y caducadas.An adherence history of confirmed and expired doses.

Cómo está hechoHow it is built

  • React Native con Expo y TypeScript: una sola base de código para Android, iOS y web.React Native with Expo and TypeScript: one codebase for Android, iOS and web.
  • Firebase con el control de acceso aplicado en las reglas de seguridad de la base de datos y 11 índices compuestos.Firebase with access control enforced in the database security rules and 11 composite indexes.
  • Lógica de negocio separada por entidad y funciones puras cubiertas por 18 tests unitarios.Business logic split by entity and pure functions covered by 18 unit tests.
  • Integración continua con GitHub Actions y despliegue web en Vercel.Continuous integration with GitHub Actions and web deployment on Vercel.
