RecuerdaMed

Una app multiplataforma que ayuda a personas mayores y polimedicadas a no saltarse ninguna toma, y que avisa a cuidadores y familiares si alguna se queda sin tomar.

Qué hace

  • Cada medicación guarda dosis, forma, notas y una foto de referencia opcional, tomada con la cámara o desde la galería.
  • Pautas diarias, por días de la semana o cada X horas. Cada toma pasa por programada, pendiente, confirmada o caducada según su ventana de tiempo.
  • Notificaciones locales de recordatorio, aviso y caducidad, y avisos push a los vinculados.
  • Tres roles: el paciente invita a cuidadores y familiares, decide quién ve sus tomas y puede retirar el acceso cuando quiera.
  • Historial de adherencia con las tomas confirmadas y caducadas.

Cómo está hecho

  • React Native con Expo y TypeScript: una sola base de código para Android, iOS y web.
  • Firebase con el control de acceso aplicado en las reglas de seguridad de la base de datos y 11 índices compuestos.
  • Lógica de negocio separada por entidad, con funciones puras cubiertas por 18 tests unitarios.
  • Integración continua con GitHub Actions y despliegue web en Vercel.
