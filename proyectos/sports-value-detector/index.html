Sports Value Detector

Calcula sus propias probabilidades para mercados de fútbol y tenis y las compara con la cuota de cierre de casas de referencia, el listón más exigente. Ningún modelo la bate de forma consistente, y el proyecto lo cuenta tal cual.

Qué hace

  • Reúne 5 ligas de fútbol en 5 temporadas (unos 8.900 partidos) y unos 13.000 partidos de la ATP, cruzando dos fuentes con un 99,8 % de coincidencia.
  • Calcula probabilidades con modelos propios y las compara con la cuota de cierre.
  • Registra cuotas de mercados sin histórico gratuito, como córners y tarjetas, para construir uno propio.
  • Un panel con FastAPI y React para explorar partidos, backtests y calibración.

Cómo está hecho

  • Sin fugas de información. Las variables se calculan en una sola pasada cronológica, y hay tests que truncan y alteran el futuro para comprobar que el pasado no cambia.
  • Validación temporal con dos temporadas distintas fuera de muestra, para no elegir un modelo por suerte.
  • Modelos: regresión logística para el 1X2, Dixon-Coles para los goles y Elo por superficie con regresión logística para el tenis.
  • Escepticismo con los aciertos: un backtest con un ROI del +1,0 % resultó ser ruido (+0,24 sigmas) y se descartó.
