Qué hace

  • Descarga precios diarios y cuentas anuales y los guarda en SQLite. Un dato que falta se muestra como «s/d»: nunca se inventa.
  • Puntúa cada empresa de 0 a 100 con ocho criterios y lista aparte las banderas rojas.
  • Avisa al entrar en la zona de interés o quedarse a menos del 3 %, al cruzar la media de 200 sesiones o al aparecer una bandera roja nueva.
  • Cada aviso de zona incluye los últimos titulares y mi nota sobre el valor.

Cómo está hecho

  • Pesos y umbrales en un YAML, para ajustar el método sin tocar código.
  • Una tabla antispam evita repetir el mismo aviso durante 5 días.
  • Salida en JSON para un flujo de n8n o envío directo por la API de Telegram.
  • Panel FastAPI sin endpoints de escritura y un modo demo con datos sintéticos.
