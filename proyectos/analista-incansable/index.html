Analista incansable

Vigila cada día una lista de acciones, puntúa cada empresa por sus fundamentales y avisa cuando algo merece una segunda mirada. Analiza y vigila; nunca predice ni opera.Every day it watches a list of stocks, scores each company on its fundamentals and flags anything worth a second look. It analyses and watches; it never predicts or trades.

Qué haceWhat it does

  • Descarga precios diarios y cuentas anuales y los guarda en SQLite. Un dato que falta se muestra como «s/d»: nunca se inventa.Downloads daily prices and annual statements into SQLite. Missing data is shown as “n/a”: it is never invented.
  • Puntúa cada empresa de 0 a 100 con ocho criterios y lista aparte las banderas rojas.Scores each company from 0 to 100 on eight criteria and lists red flags separately.
  • Avisa al entrar en la zona de interés o quedarse a menos del 3 %, al cruzar la media de 200 sesiones o al aparecer una bandera roja nueva.Alerts when a stock enters its zone or gets within 3%, crosses the 200-day average or gets a new red flag.
  • Cada aviso de zona incluye los últimos titulares y la nota manual del valor.Every zone alert includes the latest headlines and the manual note for the stock.

Cómo está hechoHow it is built

  • Pesos y umbrales en un YAML, para ajustar el método sin tocar código.Weights and thresholds in YAML, to tune the method without touching code.
  • Una tabla antispam evita repetir el mismo aviso durante 5 días.An anti-spam table stops the same alert repeating for 5 days.
  • Salida en JSON para un flujo de n8n o envío directo por la API de Telegram.JSON output for an n8n workflow, or straight to the Telegram API.
  • Panel FastAPI sin endpoints de escritura y un modo demo con datos sintéticos.A FastAPI panel with no write endpoints and a demo mode with synthetic data.
