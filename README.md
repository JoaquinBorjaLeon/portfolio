# joaquinborjaleon.com

Personal portfolio of Joaquín Borja León, in Spanish and English, deployed on Cloudflare Pages.

- `index.html`: home with a short summary of every project, experience, education and contact.
- `proyectos/<project>/`: one page per project with screenshots, my part, how it is built and links.
- `assets/`: shared stylesheet and script (language switch, light and dark theme, header menu, reveal on scroll).
- `img/`: screenshots, cover images in light and dark versions and link preview images, all from the real apps or their demo data.
